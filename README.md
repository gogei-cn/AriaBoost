# AriaBoost

> AriaBoost 是一款通用 Aria2 RPC 智能下载优化工具，兼容 Motrix、Aria2 WebUI、原生 Aria2 等全部 Aria2 客户端。内置卡尔曼滤波、贝叶斯自适应调参、K-Means 网速聚类，自动识别网络波动，智能暂停/恢复任务，抓住服务器带宽窗口期，突破持续会话限速，长期提升平均下载速度。

## 核心原理：重启任务为什么能够提速？

很多文件服务器、网盘源存在**动态会话限速机制**：
服务器会对长期持续的TCP连接进行流量管控，同一组连接会话运行一段时间后触发限速；
限速规则绑定**连接会话**，新建连接会重新进入带宽分配窗口期，短暂放开流量限制。

同时 Aria2 长期下载伴随痛点：

1. **会话限速**
   长连接持续下载一段时间后，服务器主动压低单任务带宽，老连接难以恢复速度；
2. **僵死分片连接**
   部分分片源拥堵、被限流，Aria2 维持无效连接持续占用线程，不会主动重建会话。

### 暂停+恢复任务的作用

重启任务**不会删除本地已下载分片**，行为等价于：
销毁当前全部TCP会话 → 重新向服务器发起大量新分片请求 → 获取新一轮带宽窗口期。

本工具持续监控实时下载速率，智能识别稳定低速区间：
过滤瞬时网络抖动，只在确认进入持续限速状态时触发任务重启，抢占新的流量窗口。

> ⚠️ 重要声明

1. 本工具**不能突破你自身宽带物理上限**；
2. 无法永久解除服务器硬性带宽封锁，仅利用服务器会话限速策略，抓住短暂提速窗口；
3. 效果取决于源站限速策略，部分严格IP限流服务器可能无明显提升。

## 功能亮点

1. **卡尔曼速度平滑 + 速度趋势预测**
   过滤瞬时网速毛刺，区分短暂抖动与持续性限速，避免误重启。
2. **贝叶斯自适应调参**
   自动优化触发阈值、热身时长、低速计数、速度过滤系数，适配不同服务器限速策略。
3. **网速模式聚类**
   自动区分高速/稳定/持续限速三种下载曲线，每种场景独立保存最优触发策略。
4. **鲁棒峰值计算算法**
   剔除瞬时突发速度毛刺，防止基准带宽虚高，避免过于激进频繁重启。
5. **末期保护机制**
   文件临近下载尾声时自动降低重启频率；文件剩余量极低时直接禁用优化。
6. **异常检测 & RPC 熔断保护**
   识别畸形异常网速曲线；RPC连接异常自动熔断重试，程序不会直接闪退崩溃。
7. 浅色/深色双主题界面
8. 完整图形化设置面板，无需手动编辑配置文件
9. 参数状态持久化，重启程序保留训练数据

## 快速使用

### 方式 1：下载发行版（推荐普通用户）

前往 [Releases](https://link.wtturl.cn/?target=https%3A%2F%2Fgithub.com%2Fgogei-cn%2FAriaBoost%2Freleases&scene=im&aid=497858&lang=zh) 页面，下载由 GitHub Actions 自动编译构建的安装包，解压直接运行。

### 方式 2：本地源码运行

1. 启动你的 Aria2 客户端，开启 RPC 服务；
2. 源码运行 `python src/main.py`；
3. 首次启动自动生成 `config.json`；
4. 打开软件「设置」，填写 RPC 地址与令牌，保存；
5. 点击「开始优化」自动监控活跃下载任务。

## 界面说明

### 顶部控制栏

- 开始优化：启动后台监控线程，自动接管下载调速逻辑
- 停止优化：暂停全部自动操作，仅展示监控数据
- 设置：可视化修改全部参数、切换深浅色主题
- 统计：查看总重启次数、平均速度、峰值、带宽利用率

### 实时监控面板

实时展示：当前速度、基准峰值、动态阈值、热身时长、全局平均、下载进度、运行状态、重启次数、聚类模式。
底部日志框输出全部预测、重启、异常、配置日志。

## 关键配置说明

所有参数均可在图形化设置面板修改，核心配置：

- `RPC_URL`：Aria2 RPC 服务地址
- `RPC_TOKEN`：Aria2 访问令牌
- `USE_PATTERN_CLUSTER`：网速聚类开关（修改后重启生效）
- 速度触发、预测、抖动过滤相关阈值区间
- THEME：light /dark 界面主题

## 使用建议

1. **热身时长不要设置过短**
   下载刚启动速度处于上升阶段，程序跳过判定，避免开局错误重启。
2. **不建议手动设置极低触发阈值**
   过于频繁重建会话，可能触发服务器更严格限流，交给贝叶斯自动调参效果更佳。
3. **优先用于存在会话限速的下载源**
   直连不限速的本地 / 内网资源，开启优化几乎没有收益。
4. 多任务同时下载场景谨慎使用，建议单次仅监控一个主要任务。

## 常见问题

1. **启动报错 RPC 解包异常**
   未打开 Aria2 客户端，或 RPC 地址 / 令牌填写错误；程序内置熔断，不会直接闪退，日志会打印连接提示。
2. **开启聚类但界面显示未启用**
   删除状态文件，保存设置后重启程序，等待采集足够网速样本后生效。
3. 设置数字调节框看不到上下箭头
   已内置修复样式，切换主题或重启设置窗口即可正常显示。
4. 下载几乎没有提速效果
   目标服务器不限会话连接、或者服务器采取 IP 级限流，重建连接无法获取带宽窗口。
